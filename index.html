เชื่อมต่อ Google Sheets API
ข้อมูลการลงทะเบียนจะถูกบันทึกลง Google Sheets จริงหลังตั้งค่านี้

วาง URL ที่ได้จาก Deploy ใน Google Apps Script Editor

📖
วิธีการติดตั้ง Google Apps Script
ทำครั้งเดียว ใช้ได้ตลอด
1
เปิด Google Sheets ใหม่
สร้าง Spreadsheet ใหม่ใน Google Drive ตั้งชื่อว่า "ระบบลงทะเบียนการอบรม BU"
2
เปิด Apps Script Editor
ไปที่เมนู Extensions → Apps Script
3
วาง Code และบันทึก
ลบ code เดิม → วาง google-apps-script-v2.js → กด Save (Ctrl+S)
4
Run ฟังก์ชัน setup()
เลือกฟังก์ชัน setup แล้วกด Run เพื่อสร้าง Sheet headers (ทำครั้งแรกครั้งเดียว)
5
Deploy เป็น Web App
Deploy → New deployment
Type: Web App · Execute as: Me · Who has access: Anyone
✓
คัดลอก URL มาวางในช่องด้านบน
URL จะขึ้นต้นด้วย https://script.google.com/macros/s/...
🔐
เปลี่ยนรหัสผ่าน Admin
รหัสผ่านจะถูกเก็บในไฟล์ HTML เท่านั้น
⚠️ หลังเปลี่ยนรหัสผ่าน กรุณา Download ไฟล์ HTML ใหม่และเปิดจากไฟล์ที่ download มา เพราะรหัสผ่านเก็บอยู่ในไฟล์
